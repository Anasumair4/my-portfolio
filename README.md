# DevOps Engineer Portfolio

## Quick setup

1. Open `index.html` in a browser, or serve it with Nginx / any static web server.
2. Replace:
   - `YOUR_GITHUB_USERNAME`
   - `YOUR_LINKEDIN_USERNAME`
   - `YOUR_EMAIL@example.com`
   - `YOUR_REPO_1`, `YOUR_REPO_2`, `YOUR_REPO_3`
3. Edit the three project descriptions so they exactly match your real projects.
4. Push the folder to GitHub.
5. Deploy it to S3 + CloudFront, GitHub Pages, Netlify, Vercel, or your own AWS/Nginx server.

## Included DevOps showcase features

- Three.js animated 3D infrastructure/network background
- Responsive design
- AWS / Docker / Linux / networking / CI/CD skill matrix
- DevOps lifecycle visualization
- Production-style architecture section
- Live public GitHub repository loader using the GitHub REST API
- GitHub and LinkedIn buttons
- Terminal-style hero section
- Scroll reveal animations
- Mobile navigation

## Important

The project cards are intentionally written as DevOps-oriented examples. Before using this as a CV/job portfolio, change any project claim that does not exactly describe something you personally built.
